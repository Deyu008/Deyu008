## 在做的项目

- **[paperlab](https://github.com/Deyu008/paperlab)** — 论文研究 agent:给一个研究问题,从文献综述、沙箱实验一路跑到 LaTeX 成稿和多角色评审。核心是防造假——论文里每个数字都必须能追溯到实验记录。
- **[ALF](https://github.com/Deyu008/ALF)** — ICIP 2026 论文 *"ALF: Sharpness-Aware Adaptive Layer Fusion for Training-Free Anomaly Detection"* 的官方代码,整理中。
- **[witherbloom-cycle](https://github.com/Deyu008/witherbloom-cycle)** — 业余项目:零依赖的像素风动作 RPG,渲染、碰撞、音频全部手写,约 1.25 万行,带 216 项回归测试。
- **[visulite](https://github.com/Deyu008/visulite)** — 科研数据快速出图的小工具。
